# Roadmap

This project does not publish a roadmap.

Planned work is not tracked in the repository. What shipped is in the
[CHANGELOG](../CHANGELOG.md), which is the source of truth and the only
forward-or-backward claim this repo makes about itself.

Why the file is still here: released CHANGELOG entries cite this path,
and rewriting shipped release notes to tidy a link is worse than the
link. The entries that used to live here — open work, and the work
deliberately declined with the reasoning that declined it — moved to the
maintainer's memory store, which unlike a markdown file can say when one
of them has gone stale.

If you want to help, [CONTRIBUTING](../CONTRIBUTING.md) names the
highest-leverage places to start.
